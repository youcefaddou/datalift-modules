# Contribuer à DataLift

1. Lis `docs/ONBOARDING.md` puis `docs/CONVENTIONS.md`.
2. Prends un ticket dans le tableau GitHub Projects et assigne-le toi.
3. Crée une branche : `feat/<sujet-court>`, `fix/...`, `docs/...`.
4. Code, avec des tests. Lance `make lint` et `make test`.
5. Ouvre une pull request en remplissant le modèle. Au moins une relecture est obligatoire.
6. Après fusion, supprime la branche.

**Rappels :** aucune donnée réelle, aucun secret, ne modifie pas `contracts/` sans décision d'architecture.
