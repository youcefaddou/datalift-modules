# ADR-003 — Validation humaine obligatoire

- **Statut :** adoptée
- **Date :** 2026-10-07
- **Auteur :** Youcef Addou

## Contexte

L'IA peut se tromper sur une correspondance de champs, avec des conséquences métier (mauvaise facture dans l'ERP).

## Décision

Aucun flux n'est exécutable sans validation humaine enregistrée (auteur, date, version du flux).

## Conséquences

Fiabilité et responsabilité claires. Une étape de plus pour l'utilisateur, compensée par une interface rapide.
